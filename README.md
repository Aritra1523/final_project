# 🛒 Grocery Basket

A modern and responsive grocery shopping application built with **Next.js, Redux Toolkit, Axios, and Tailwind CSS**.

## ✨ Features

* Product listing with API integration
* Search, category filter & price sorting
* Add, remove & update cart items
* Persistent cart using LocalStorage
* Automatic discount calculation
* Promo code support
* Undo cart actions
* Responsive UI
* Loading & error states

## 🛠️ Tech Stack

* **Next.js**
* **React**
* **Redux Toolkit**
* **Axios**
* **Tailwind CSS**
* **DummyJSON API**

## 🚀 Getting Started

```bash
git clone https://github.com/Aritra1523/final_project.git
cd final_project
npm install
npm run dev
```

Open `http://localhost:3000`.
